Usage: symbolic-math [OPTIONS] [INPUT]...

  Simplifies each expression, solves each equation, system of equations or inequality, runs
  each command, and prints the exact result with its numeric value. Each argument is one input:
  quote it for the shell. An input holds one or more statements separated by `;`. Without an
  input the program reads lines from the standard input. All inputs of one run share their
  definitions, their assumptions and the last result (`ans` or `%`).

Options:
  -d, --digits N    significant digits of numeric values (default 32, or more when a number of the
                    input has more digits)
  -r, --real        real numbers only: symbols are real, only real solutions are given, odd roots
                    of negative numbers are real; the same as the statement domain(real)
  -q, --quaternions quaternions: j and k are units next to i (i*j = k), symbols are real, the
                    unknown of an equation is a quaternion; the same as domain(quaternion);
                    quat(a, b, c, d) works in every domain
  -n, --numeric     print numeric values instead of exact forms
  -e, --exact       print exact forms only, without the numeric line
      --functions   list the functions with all their names
      --constants   list the constants with all their names
      --units       list the units of convert(...) with their names and sizes
  -h, --help        this text
  -V, --version     the version

Numbers are exact (integers, fractions, decimals, complex with i) or have the digits asked for.
An input with a decimal point is answered in decimals. Names have ASCII and Unicode spellings:
pi or π, sqrt(2) or √2, inf or ∞, x^2 or x², <= or ≤. A line `  ~ ...` of the output is the
numeric value of the line above it, a line `note: ...` is a remark.

Examples of every kind of operation. Each line is what follows `symbolic-math` on the command
line: one or more inputs in quotes, sometimes an option before them, and after `#` what the
line shows.
